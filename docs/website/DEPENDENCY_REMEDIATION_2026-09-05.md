## Browser verification correction

The first full run caught a delayed homepage badge during its entrance fade.
The previous verifier waited for only the route wrapper and swallowed its
timeout; forcing CSS animations off did not settle delayed native animations.

The corrected verifier waits for fonts, the route entrance, all rendered finite
animations (including transparent and offscreen elements), and a 200ms quiet
interval. A five-second timeout fails the route audit. Infinite decorations do
not hold the readiness wait; they remain in the page audited by axe. The forced
animation/transition style override is removed. No contrast rule, element or axe
category is excluded, and no page color or opacity is overwritten.

An independent review identified a viewport-only readiness gap; it was removed
before the final full run. The final dependency and readiness reviews have no
remaining actionable finding. This is bounded readiness for the current page
animations, not a universal guarantee for every possible future JavaScript effect.
